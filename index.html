How this dataset was built

Extracted from the top 10,000 entries of an open Indonesian frequency corpus and cleaned down to 7,262 validated words.

View id_50k.txt
01

Upstream corpus extraction

Taken from the top 10,000 lines of hermitdave/FrequencyWords (content/2018/id/id_50k.txt), which lists Indonesian word tokens alongside raw occurrence counts from OpenSubtitles 2018 data.

02

Noise and invalid entry filtering

Audited using automated LLM screening via free Groq APIs followed by manual review to remove non-loanword English words, proper names, OCR glitches, numbers, symbols, and explicit terms.

03

Vocabulary data generation

Validated entries were processed in batches using Python scripts and free Groq APIs prompted for everyday spoken Indonesian, adding English meanings, part of speech, usage notes, collocations, and example sentences.

04

Sequential re-indexing (1 to 7,262)

After removing invalid entries, all 7,262 surviving words were re-numbered sequentially from wordId: 1 to 7262 with zero gaps, while preserving each entry's original frequencyRank.

JSON structure

vocab.json is formatted as a flat array of 7,262 objects ready for SQLite ingestion, mobile apps, or linguistic scripts.

wordId integer Sequential unique identifier (1 to 7262) after dataset cleaning.
indonesian string Target Indonesian vocabulary word.
frequencyRank integer Original rank position from id_50k.txt.
translation string English meanings separated by semicolons (;).
pos string Grammatical part of speech (noun, verb, adjective, adverb, etc.).
usageNote string Formality, slang, or cultural context note (empty string "" if none).
collocationIdn string Natural 2-to-3-word Indonesian phrase using the target word.
collocationEng string Direct English translation of collocationIdn.
exampleSentenceIdn string Natural everyday Indonesian sentence demonstrating the word in context.
exampleSentenceEng string English translation of exampleSentenceIdn.
